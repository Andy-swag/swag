快速开始

单个 Go 二进制，零前端打包依赖。

Go 1.24+ 直接编译，扫码配对手机 PWA 或一键接入新电脑节点，所有状态与密钥留在你自己的 ~/.swag/ 目录。

# 克隆仓库并验证全部单测与架构守卫
git clone https://github.com/Andy-swag/swag.git
cd swag && ./scripts/verify.sh

# 编译单二进制并启动 Hub
CGO_ENABLED=0 go build -trimpath -o ~/.local/bin/swag .
swag
# 在 Hub 上生成手机 PWA 配对二维码（10 分钟有效）
swag pair

# 生成另一台电脑（Mac / Linux 算力节点）加入命令
swag pair --computer

# 在新节点上运行配对命令后，即可通过本机 http://127.0.0.1:17788 访问
# 查看在线节点、Router 与运行中的 Worker
swag list

# 定时任务与待办中心
swag timer add "weekdays 09:00" "汇总昨夜构建状态与今日重点"
swag todo add --title "复查发布检查项" --due "今天 18:00"
swag todo ls
