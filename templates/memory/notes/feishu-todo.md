# 飞书只读 Todo 扫描与派活候选整理剧本（模板）

## 触发时间（工作日三班）
- **10:00（上午档）**：梳理当天日程、待办、审批与昨夜/今早重要消息线索。
- **14:00（午后档）**：更新午间新增任务、待跟进会议决议与阻塞事项。
- **18:30（收口档）**：盘点当日未完事项、次日重点准备与夜间可自动跑的只读调研。

## 严格只读红线
1. **只读扫描**：仅调用 `lark-cli` 的只读查询命令，严禁回复消息、严禁外发群聊、严禁代批审批、严禁修改线上数据。
2. **人在回路拍板**：将可执行候选项通过 `swag todo add --source feishu --title "..." --due "..." --link "..." --detail "..."` 写入 Swag「待办」中心，并用 `swag reply --opt` 推送带可点击按钮的飞书汇总卡片请主人拍板。

## 执行步骤
1. 未完成任务：`lark-cli task +get-my-tasks`
2. 今日/未来 24h 日程：`lark-cli calendar +agenda`
3. 待处理审批：`lark-cli approval` 只读查询
4. 重要未读 / @我线索：`lark-cli im` 只读检索
5. 对照 `memory/tasks/` 去重，避免重复派活。
