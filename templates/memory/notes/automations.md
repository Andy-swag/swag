# 自动化巡检剧本（模板）

## 1. 夜间服务健康巡检
- **触发**：每日夜间定时触发（`ops-auditor` 只读角色）。
- **动作**：检查关键构建/测试任务与节点健康状态；仅在发现异常或卡死时回报并推送审批卡。

## 2. 凌晨复盘与记忆整理（Dream）
- **触发**：每日凌晨（`dream`）。
- **动作**：
  - 沉淀当日经验、踩坑根因与验证过的命令到 `notes/pitfalls.md` / `notes/agents.md`；
  - 核对进行中任务进展，归档已完结任务，并清理过时/错误事实；
  - 提炼高频重复流程，输出「可做成 skill / 可固化脚本或流水线」提案；
  - 若配置了 `notes/dream-workspaces.md`，按声明的安全边界更新本地工作区文档/经验库并清理过期未追踪临时文件，同步只读镜像到各在线节点。
